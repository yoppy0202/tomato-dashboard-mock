前提:`docs/PK_追記_名簿管理と添付仕様.md` の挿入F〜Kを
`PROJECT_KNOWLEDGE.md` に反映してからコード作業に入る。

---

## 1. `members.html`(新規・管理者専用)

既存の`markets.html`と同じ位置づけの管理画面。デザイン・命名規則はそれに揃える。

### 1-1. 上部の集計
メトリクスカードを2枚横並びで表示。

- 「LINE連携済み」…`34/40人` のように 連携済み数/総数
- 「管理者」…`3人`

導入時に未連携者が何名残っているかを把握するための表示なので、常時見える位置に置く。

### 1-2. 検索・絞り込み
- 氏名でのキーワード検索(インクリメンタル検索でよい)
- 「追加」ボタン(新規部会員の登録)
- タブ絞り込み:すべて / 未連携 / 管理者

### 1-3. 一覧
1名1カードで縦に並べる。各カードの表示項目:

- 氏名(太字)
- 権限バッジ(管理者 / 閲覧。色で区別)
- LINE連携状況(「LINE連携済」…成功色＋チェックアイコン / 「LINE未連携」…警告色＋注意アイコン)
- 最終ログイン日時(未連携者は `—`)
- 編集アイコン

### 1-4. 編集(カードの編集アイコンから)
以下を変更できるダイアログまたは編集画面を用意する。

- 氏名の修正
- 権限の切替(閲覧 ⇄ 管理者)
- 一覧から外す(**論理削除**。物理削除しない)
- **LINE連携の解除**(機種変更・アカウント再作成時の再紐付け用)

### 1-5. 管理者2名以上の担保(重要)
権限を「閲覧」に落とす操作や、管理者を一覧から外す操作によって
**管理者が1名になる場合は、操作自体をブロックする**。

- 確認ダイアログで警告するのではなく、実行不可とする
- ブロック時は理由を明示(「管理者は2名以上必要です」)

### 1-6. 画面下部の注記
「氏名はこの名簿の値が正となり、LINEの表示名は使用されません。
部会員を一覧から外しても過去の記録は保持されます。」の旨を常時表示。

## 2. ナビゲーション帯への追加

管理者用ナビ帯に**6つ目の項目「部会員名簿」**(`members.html`)を追加する。

- `assets/nav.js` を修正
- 既存5項目(データ入力 / データ一覧 / お知らせ投稿 / 市場の管理 / 議事録)の後ろに置く
- 一般ユーザー用ナビ帯には**追加しない**(管理者専用画面のため)
- 項目が6つになるため、スマホ幅での横スクロール表示が破綻していないか確認すること

---

## 3. 未保存離脱ガードの適用

`members.html` を `assets/unsaved-guard.js` の対象に加える。

- 氏名の編集途中・追加フォーム入力途中で離脱しようとしたら警告
- `markets.html` と同じく、既存の確認ダイアログに合流させる形でよい

## 4. 議事録の添付ファイル表示の更新(`minutes-edit.html`)

添付仕様が確定したので、投稿・編集フォームの表示を合わせる。

- ファイル選択欄の下に許可形式と上限を明記:
  「PDF / Word / Excel / PowerPoint / 画像(JPEG・PNG・HEIC)。1ファイル20MBまで、最大10ファイル」
- 画像を選択した場合、「アップロード時に自動圧縮されます」の旨を表示
- モックなので実際の圧縮処理・アップロード処理は不要。表示のみでよい
