## 2. 未保存離脱ガード(共通コンポーネント)

対象:`admin.html` / `announce.html` / `markets.html` / `minutes.html`

- 共通JS(例:`assets/unsaved-guard.js`)として切り出し、各ページから読み込む
- 「未保存の変更あり」フラグを管理。入力・変更イベントでON、保存完了でOFF
- フラグONで以下をフックする:
  1. ナビ帯のリンククリック → サイト内ダイアログで遷移をキャンセル
  2. 「← TOPへ戻る」クリック → 同上
  3. `beforeunload` → ブラウザ標準の確認(文言は指定しない/できない)
- サイト内ダイアログのボタンは3つ:
  - 「保存してから離れる」(主ボタン)…そのページの保存関数を呼び、成功後に遷移
    - `admin.html`は既存の確定確認ダイアログに合流させる
    - `announce.html` / `minutes.html`は下書き保存で可
  - 「このまま離れる」(赤字)…変更を破棄して遷移
  - 「キャンセル(このページに留まる)」
- ダイアログの見た目は警告アイコン＋見出し＋説明文＋縦積みボタンの構成

## 3. 議事録ページ(新規)

### 3-1. `minutes.html`(一覧)
- 検索ボックス(キーワード。タイトル＋本文を対象、インクリメンタル検索でよい)
- カテゴリタブ:すべて / 全体協議会 / 役員協議会
- 日付範囲での絞り込みも入れる
- カード形式で日付降順に一覧表示。各カードにカテゴリバッジ・日付・タイトル・本文冒頭・添付有無
- カードクリックで詳細へ遷移
- 管理者には「新規投稿」ボタンを表示

**権限による出し分け(重要)**
- 一般ユーザーには**役員協議会タブを表示しない**。一覧にも役員協議会の議事録を出さない
- 検索も同様。一般ユーザーの検索結果に役員協議会がヒットしないこと
  (モックでもフィルタ処理の段階で除外する実装にしておく。画面側でCSSで隠すだけにしない)
- 「権限がありません」等のメッセージも出さない。存在自体を見せない

### 3-2. `minutes-detail.html`(詳細)
- カテゴリバッジ・日付・タイトル・投稿者・最終更新日時
- 本文(議題ごとの見出し＋本文の想定。改行が読みやすい行間で)
- 添付ファイル一覧:ファイル種別アイコン＋ファイル名＋ダウンロードアイコン
- **管理者にのみ**「編集」「削除」ボタンを最下部に表示
- 「← TOPへ戻る」＋ナビ帯

### 3-3. `minutes-edit.html`(投稿・編集/管理者のみ)
- カテゴリ選択(プルダウン:全体協議会 / 役員協議会)
- 日付・タイトル・本文(テキストエリア)
- 添付ファイルのアップロードUI(モックなのでファイル選択と一覧表示まで。実アップロードは不要)
- 「下書き保存」「投稿する」ボタン
- 未保存離脱ガードの対象
